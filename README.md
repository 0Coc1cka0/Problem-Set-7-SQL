
#Problem Set 7 — SQL (Модуль 7)

Практические задания по работе с реляционными базами данных SQLite, фильтрации данных, объединению таблиц (JOIN), агрегации и вложенным запросам.

#Структура репозитория:

• songs/ (1.sql – 8.sql) — анализ музыкальной библиотеки: сортировка треков по темпу и длительности, фильтрация по аудио-метрикам (danceability, energy, valence), расчёт средних значений и поиск исполнителей через вложенные запросы.
• movies/ (1.sql – 13.sql) — работа со связанными таблицами базы кинофильмов (movies, people, stars, directors, ratings): выборки по годам выпуска, рейтингам и поиск совместных работ актёров с помощью многоуровневых JOIN и группировки (GROUP BY, HAVING).
• fiftyville/ (log.sql, answers.txt) — детективное расследование кражи талисмана CS50: пошаговый анализ логов парковки, банкоматов, телефонных звонков и авиарейсов для установления личности вора, маршрута побега и сообщника.

#Использованные технологии и инструменты:

• Язык запросов: SQL (SQLite)
• Инструменты: DB Browser for SQLite, VS Code

#Примечание о базах данных:

В целях оптимизации репозитория исходные файлы баз данных (songs.db, movies.db, fiftyville.db) исключены из загрузки. Для локального запуска запросов используются стандартные учебные базы данных курса CS50 (Problem Set 7: SQL).
